Typography — 4 styles

Audited down from 16, then from 6. Two weights system-wide: 400 and 600 — no 500, no 700, except JetBrains Mono's display tier, which ships no 600 file. A new visual need is a modifier on one of these four, never a 5th named style.

Motion

Near none, by design — this is a glance-mode tool, not a marketing site. The spine and panes never animate on their own; only discrete controls get a press or open transition.

Locked rules these tokens serve

Each value above enforces one of the architecture rules in CLAUDE.md — changing a token without checking this list is how a rule gets silently broken.

1
Three scopes, one column each. Column widths are fixed in regions.js (320px / 480px / flex), not a spacing token.
2
The spine never scrolls. .spine is flex:0 0 auto; only .col panes get overflow:auto.
3
Coral is the escalation channel only — three-element budget, above.
5
Every figure carries its scope in its label. The label style is what carries "across 2 accounts" next to every display figure.
7
Account sort is outstanding descending, always. A process rule, not a visual one — why cards never reorder when a badge colour changes.
