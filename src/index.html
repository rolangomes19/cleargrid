ClearGrid Borrower Profile redesign

Prototype, self-graded. Fixture data only. Designed for desktop screens 1366px and wider.

An agent gets the 5% of cases that need judgement. The profile answers the five questions they ask first, with zero clicks, in English and Arabic.

  • Spine + scope columns. Owed, how late, promise, why this case, and which channels are allowed sit in one pinned strip. Below it, one column each for person, account and activity.
  • Why this reached you. A line computed from fields that exist today (dispute, hardship, broken promises). A proposed field: it does not exist in the system today.
  • Compliance before the click. Each channel shows its state, reason and rule source (CBUAE 5.2.5, SAMA) before the agent tries it.
  • One dictionary, full mirror. Arabic is generated from the same dictionary, with Arabic type sizes, Western digits and isolated IDs.
